# Планировщик мечты

## Запуск
Двойной клик по `start.bat` (нужен Python) или в папке: `python -m http.server 8000`, затем http://localhost:8000
Открывать через сервер обязательно, иначе браузер не даст загрузить .glb и текстуры.

## 3D-модели (папка models/)
Положите файл, и карточка в каталоге включится сама:
  table.glb, stool.glb, wardrobe.glb, nightstand.glb, dresser.glb, tv.glb
Уже лежат (присланный набор, цвета по палитре квартиры):
  table_oak.glb, table_cone.glb, table_round.glb, chair_cognac.glb (повёрнут в коде: ry 180), chair_shell.glb, chair_green.glb,
  armchair_wood.glb, armchair_cognac.glb (в присланном armchair1.glb не было материала: обивка покрашена в коньячный, ножки в чёрный),
  armchair_green.glb (из armchair2.glb без материала: корпус зелёный, сиденье и подушка кремовые, полозья чёрные; файл в 1,5 раза крупнее кресла, размер задан в каталоге), chair_walnut.glb (из chair5.glb без материала: каркас орех, сиденье тёмно-синее; файл в 1,7 раза крупнее стула), bed_single.glb (Bed3.glb: заменила встроенную односпальную; в файле нестандартные единицы, размер по матрасу 2 м → 136 × 217 см), sofa_teal.glb (sofa4.glb как есть: свои материалы и размер), sofa_classic.glb (из sofa2.glb без материала: обивка цвета «Диван, ткань», подушки зелёные, белая и коньячные, ножки тёмное дерево; файл 282 см, по умолчанию 240), sofa_3.glb, bed_green.glb, bed_panel.glb (повёрнута в коде: ry -90; чёрное основание из цветов точек вынесено в серую часть 'base', её перекрашивает смена цвета)
Если модель смотрит не вперёд (+Z), укажите в её строке CATALOG поворот ry в градусах.
Требования: ось Y вверх, ширина по X, глубина по Z; единицы и начало координат любые
(модель масштабируется под размеры из CATALOG в index.html). Лучше до 5 МБ на файл.
Новая позиция: добавьте строку в массив CATALOG в index.html (id, cat, name, w, d, h в мм, min/max, file).

## Текстуры (папка textures/)
  floor_wood.jpg (повтор каждые 1,5 м), floor_tile.jpg (повтор каждый 1 м)
Если файла нет, используется встроенная процедурная текстура.

## Фото вариантов (папка images/)
Для карточек каталога: images/<id>.jpg (например table.jpg). Для присланных моделей лежат превью, отрисованные по самим моделям. Если фото нет, показывается значок. Новый вариант мебели: строка в CATALOG с тем же cat и новым id.

## Встроенная мебель без файлов (рисуется кодом)
  Детская кровать-домик (kidsbed), ковры: берберский (rug_berber), с бордюром (rug_green),
  круглый джутовый (rug_round), вешалка напольная (rack), обувница (shoecab), компьютерный стол (desk_pc),
  ТВ-тумба белая с рифлением (tv_fluted), журнальный столик дубовый (coffee_oak),
  шкафы: дуб с графитом (wardrobe_oak), с зеркалом и антресолями (wardrobe_mirror), белый с антресолями (wardrobe_white), стеллаж для книг (bookcase).
  Ковры лежат «слоем» на полу: мебель может стоять на них, но ковёр не кладётся на другой ковёр, под стены и перегородки.

## Пол в комнатах (вкладка «Ремонт»)
  Доска светлая, дуб ёлочкой, дуб натуральный, орех, серый ламинат, микроцемент — процедурные текстуры. Кухня и санузлы не меняются.
